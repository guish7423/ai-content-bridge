}

## 6. RISK REGISTER

| Risk | Probability | Impact | Mitigation |
|------|-----------|--------|------------|
| Template inheritance breaks existing routes | Medium | High | Test each template individually after conversion |
| CSS consolidation causes visual regressions | High | Medium | Visual diff before/after on each template |
| Toast system conflicts with HTMX swap | Low | Medium | Test HTMX events fire correctly with toast |
| Live preview API calls timeout | Low | Low | AbortController + 500ms debounce + cache |
| 3D tilt causes performance issues on mobile | Medium | Low | Disable tilt on touch devices via `matchMedia` |
| Light theme WCAG fixes change visual identity | Low | Medium | Keep dark theme as primary experience |
| Removing Anime.js breaks existing animations | Low | High | Audit: Anime.js is imported but never called — no breakage |
