# Product Hunt Launch — AI Content Bridge

## Tagline (120 char max)
**China → Global in One Click.** AI-powered localization that transforms Chinese content into culturally-adapted English posts for X, LinkedIn, and Reddit.

## Description

### Headline
Chinese entrepreneurs build world-class products. Now they can tell their story globally.

### Body
Chinese entrepreneurs and creators face a unique challenge: their content is brilliant, but it doesn't resonate globally. Direct translation loses cultural context, humor, and relevance.

**AI Content Bridge** is a 3-step localization pipeline:
1. **Analyze** — AI extracts the core message, target audience, and key points
2. **Localize** — Deep cultural adaptation for international audiences (idioms, concepts, examples)
3. **Adapt** — Optimized formatting for each platform (X threads, LinkedIn professional, Reddit community)

### Key Features ✨
- **3-step prompt chain** — Not just translation, real cultural adaptation
- **Multi-platform output** — One Chinese post → X thread, LinkedIn article, Reddit post
- **Direct publishing** — Post to X and LinkedIn with one click
- **HTMX-powered UI** — Minimal JavaScript, dark theme, fast
- **CLI + API** — Integrate into your existing workflow
- **Mock mode** — Try it without any API keys

### Pricing
- **Free** → 10 translations/month
- **Starter** → $19/mo (100 translations, 1 social account)
- **Pro** → $49/mo (unlimited, all platforms)

### Tech Stack
Python 3.12+, FastAPI, DeepSeek API ($0.07/M tokens), HTMX, Jinja2, Tweepy
